# 校园照片墙 - 协作指南

写给协作者：本文档说明如何在不修改任何代码的前提下，向照片墙添加、编辑或删除图集。

> **页面与资源路径约定**：HTML 页面位于 `pages/html/` 下，组件在 `components/`、数据在 `data/`、样式在 `css/`、图片在 `image/`。页面中引用资源统一使用相对路径（如 `../../components/mc-navbar.js`、`../data/...`）。**不要改动现有页面的脚本与样式引用方式**，否则组件会加载失败。

### 数据加载原理（js/app.js）

```
1. 读取 data/folders.json          → 获取所有图集文件夹名数组
2. 对每个文件夹名：
   请求 data/<文件夹>/<文件夹>.json → 获取图集元数据
3. 取 cards[0] 作为封面卡片
4. 图片路径拼接规则：data/<文件夹>/<cards[i].image>
5. 详情页通过 article.html?id=<文件夹> 读取对应图集
```

### 页面跳转关系

| 来源 | 去向 | 说明 |
|------|------|------|
| 首页分类模块 | `category.html?cat=<分类名>` | 查看某一分类下的图集 |
| 任意卡片 / 搜索结果 | `article.html?id=<文件夹>` | 进入图集详情页 |
| 导航栏搜索 | `search.html` | 全局搜索结果页 |
| 顶部头像 | `login.html` | 登录页 |

## 二、添加新图集（完整步骤）

### 第 1 步：在 `data/` 下新建文件夹

```
data/毕业季合影/
```

> **命名建议**：使用中文短名或英文短横线，避免空格和特殊字符。

### 第 2 步：放入照片文件

```
data/毕业季合影/1.jpg
data/毕业季合影/2.jpg
data/毕业季合影/3.png
```

> ⚠️ **注意**：图片文件名不要包含中文（避免编码问题），建议用数字或英文命名。

### 第 3 步：创建图集元数据 JSON 文件

**文件名必须与文件夹名完全一致**（包括大小写），后缀为 `.json`：

```
data/毕业季合影/毕业季合影.json
```

**完整模板**（复制后按需修改）：

```json
{
  "title": "毕业季合影",
  "category": "毕业季",
  "categories": ["毕业季"],
  "categoryColors": ["#16a085"],
  "date": "2026-06-15",
  "photographer": "张三",
  "location": "学校礼堂前",
  "intro": "2026届毕业生大合影，记录青春最后一面。",
  "cards": [
    {
      "title": "全景合影",
      "intro": "全体毕业生与老师合影",
      "image": "1.jpg",
      "date": "2026-06-15"
    }
  ],
  "content": "<h2>毕业快乐</h2><p>四年时光，感谢相遇。</p>"
}
```

**空白模板**：

```json
{
  "title": "",
  "category": "",
  "categories": [""],
  "categoryColors": [""],
  "date": "",
  "photographer": "",
  "location": "",
  "intro": "",
  "cards": [
    {
      "title": "",
      "intro": "",
      "image": "",
      "date": ""
    }
  ],
  "content": ""
}
```

### 第 4 步：注册到 `data/folders.json`

打开 `data/folders.json`，将新文件夹名加入数组：

```json
[
  "示例-校园风光",
  "示例-毕业季合影",
  "示例-运动会",
  "毕业季合影"
]
```

> ⚠️ **这是最容易忘记的一步！** 不加进 `folders.json`，网页不会加载该图集。

### 第 5 步：让它出现在对应分类页

分类页（`category.html`）会自动读取 `data.folders.json` 并按 `category` / `categories` 分面，**无需手动配置**。只要你在第 3 步的 JSON 里填对了分类字段，图集就会出现在该分类的 Tab 面板中。

如果你想让某个分类在**首页**的分类模块里露出，打开 `pages/html/index.html`，找到对应的 `<section class="category-section">`，按已有结构补一个 `cards-container` 占位节点即可（渲染逻辑在 `js/app.js` 中会自动填充）。

## 三、字段说明

### 顶层字段

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `title` | ✅ | 图集标题，显示在详情页和卡片上 | `"毕业季合影"` |
| `category` | ✅ | 主分类（见下方分类列表） | `"毕业季"` |
| `categories` | ✅ | 分类数组，可填多个 | `["毕业季", "校园风光"]` |
| `categoryColors` | ❌ | 对应分类的标签颜色，不填则自动分配 | `["#16a085"]` |
| `date` | ✅ | 拍摄日期，格式 `YYYY-MM-DD`，用于排序 | `"2026-06-15"` |
| `photographer` | ❌ | 摄影师名字，显示在详情页 meta 区 | `"张三"` |
| `location` | ❌ | 拍摄地点 | `"学校礼堂前"` |
| `intro` | ✅ | 一句话简介，显示在卡片底部 | `"2026届毕业生大合影"` |
| `cards` | ✅ | 照片数组，每项对应一张照片 | 见下方 |
| `content` | ❌ | 详情页额外介绍文字，支持 HTML | `"<h2>毕业快乐</h2>"` |

### `cards[]` 子字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | ✅ | 单张照片标题 |
| `intro` | ❌ | 单张照片说明文字 |
| `image` | ✅ | 照片文件名（相对于当前文件夹） |
| `date` | ❌ | 单张照片日期，不填则继承顶层 `date` |

## 四、分类列表

代码中预置了以下分类（`js/app.js` 中的 `CATEGORIES` 数组）：

| 分类名 | 图标 | 默认颜色 |
|--------|------|----------|
| `校园风光` | 🏞️ | `#4a90d9` |
| `课堂瞬间` | 📖 | `#e67e22` |
| `社团活动` | 🎸 | `#9b59b6` |
| `体育竞技` | 🏀 | `#e74c3c` |
| `毕业季` | 🎓 | `#16a085` |
| `其他` | 📷 | `#7f8c8d` |

- `category` 和 `categories` 字段填写上述分类名即可
- 颜色会自动分配，也可以在 `categoryColors` 中自行指定十六进制色值
- 如果填了不在列表中的分类名，系统会**自动生成稳定颜色**

> 如需新增分类，只需在第 3 步的 JSON 里直接写新分类名；它会出现在分类页的 Tab 中，并自动获得配色。若要固定其颜色和图标，需由维护者修改 `js/app.js` 的 `CATEGORIES` 数组。

## 五、编辑现有图集

1. 找到 `data/<图集文件夹>/<图集名>.json`
2. 修改 JSON 内容（增删 `cards`、改文字等）
3. 如果添加了新照片文件，确保 `image` 字段指向正确文件名
4. 提交更改

---

## 六、删除图集

1. 删除 `data/` 下对应的整个文件夹
2. 打开 `data/folders.json`，从数组中移除该文件夹名
3. 提交更改

---

## 七、注意事项（重要）

| 事项 | 说明 |
|------|------|
| ⚠️ JSON 必须合法 | 逗号不能多也不能少，引号必须是双引号。推荐用 VS Code 编辑，自带 JSON 校验 |
| ⚠️ 文件名必须匹配 | JSON 文件名必须与文件夹名**完全一致**，否则 `fetch()` 会 404 |
| ⚠️ 图片路径 | `cards[].image` 只写文件名，系统自动拼接为 `data/<文件夹>/<文件名>` |
| ⚠️ 图片缺失 | 图片加载失败时会显示"暂无图片"占位图，不影响页面运行 |
| ⚠️ 不要改动组件引用 | 页面通过 `../../components/*.js` 加载 Web Components，移动或重命名组件会导致白屏 |
| ✅ 图片压缩 | 建议上传前压缩图片，避免仓库体积过大 |
| ✅ 同步 folders.json | 每次增删图集后，**务必**同步更新 `folders.json` |

## 八、本地预览方法

由于项目使用 `fetch()` 加载本地 JSON，直接双击 HTML 文件会因浏览器安全限制（CORS）无法加载数据。需要启动本地服务器：

### VS Code 插件

安装 `Live Server` 插件 → 右键 HTML 文件 → `Open with Live Server`

## 九、Git 协作流程

1. 从最新 `main` 分支拉取代码
2. 创建自己的分支：`git switch -c feature/add-<图集名>`
3. 按上述步骤添加 / 修改图集
4. 提交并推送：
   ```bash
   git add .
   git commit -m "feat: 添加毕业季合影图集"
   git push -u origin feature/add-毕业季合影
   ```
5. 在 GitHub 上发起 Pull Request，等待 Review 后合并

### 提交信息规范

| 类型 | 说明 | 示例 |
|------|------|------|
| `feat` | 新增图集 | `feat: 添加毕业季合影图集` |
| `update` | 更新已有图集 | `update: 补充运动会图集照片` |
| `fix` | 修复数据问题 | `fix: 修正文件夹名大小写` |
| `docs` | 仅文档变更 | `docs: 更新协作指南` |

如有疑问，请在仓库提 Issue 或联系项目维护者。
