# 校园照片墙 - 协作指南

写给协作者**：本文档说明如何在不修改任何代码的前提下，向照片墙添加、编辑或删除图集。

---

## 一、项目结构速览

```
项目根目录/
├── index.html              # 首页（轮播 + 分类模块）
├── wall.html               # 照片墙（筛选 / 搜索 / 瀑布流）
├── detail.html             # 图集详情页
├── css/
│   └── style.css           # 公共样式
├── js/
│   └── app.js              # 核心逻辑（数据加载、卡片渲染、导航栏）
├── data/
│   ├── folders.json        # 图集索引（必须维护）
│   ├── 毕业季合影/          # 一个图集 = 一个文件夹
│   │   ├── 毕业季合影.json  # 图集元数据（必须与文件夹同名）
│   │   ├── 1.jpg
│   │   └── 2.jpg
│   ├── 示例-图书馆黄昏/
│   └── 示例-运动会/
└── CONTRIBUTING.md         # 本文件
```

### 数据加载原理（app.js）

```
1. 读取 data/folders.json       → 获取所有图集文件夹名数组
2. 对每个文件夹名：
   请求 data/<文件夹>/<文件夹>.json → 获取图集元数据
3. 取 cards[0] 作为封面卡片
4. 图片路径拼接规则：data/<文件夹>/<cards[i].image>
```

## 二、添加新图集（完整步骤）

### 第 1 步：在 `data/` 下新建文件夹

```
data/毕业季合影/
```

> **命名建议**：使用中文短名或英文短横线，避免空格和特殊字符。

### 第 2 步：放入照片文件

```
data/毕业季合影/1.jpg
data/毕业季合影/2.jpg
data/毕业季合影/3.png
```

> ⚠️ **注意**：图片文件名不要包含中文（避免编码问题），建议用数字或英文命名。

### 第 3 步：创建图集元数据 JSON 文件

**文件名必须与文件夹名完全一致**（包括大小写），后缀为 `.json`：

```
data/毕业季合影/毕业季合影.json
```

**完整模板**（复制后按需修改）：

```json
{
  "title": "毕业季合影",
  "category": "毕业季",
  "categories": ["毕业季"],
  "categoryColors": ["#16a085"],
  "date": "2026-06-15",
  "photographer": "张三",
  "location": "学校礼堂前",
  "intro": "2026届毕业生大合影，记录青春最后一面。",
  "cards": [
    {
      "title": "全景合影",
      "intro": "全体毕业生与老师合影",
      "image": "1.jpg",
      "date": "2026-06-15"
    },
    {
      "title": "班级合影",
      "intro": "计算机系1班",
      "image": "2.jpg",
      "date": "2026-06-15"
    },
    {
      "title": "拨穗瞬间",
      "intro": "校长拨穗",
      "image": "3.png",
      "date": "2026-06-15"
    }
  ],
  "content": "<h2>毕业快乐</h2><p>四年时光，感谢相遇。</p>"
}
```

### 第 4 步：注册到 `data/folders.json`

打开 `data/folders.json`，将新文件夹名加入数组：

```json
[
  "示例-图书馆黄昏",
  "示例-运动会",
  "毕业季合影"
]
```

> ⚠️ **这是最容易忘记的一步！** 不加进 `folders.json`，网页不会加载该图集。

## 三、字段说明

### 顶层字段

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `title` | ✅ | 图集标题，显示在详情页和卡片上 | `"毕业季合影"` |
| `category` | ✅ | 主分类（见下方分类列表） | `"毕业季"` |
| `categories` | ✅ | 分类数组，可填多个 | `["毕业季", "校园风光"]` |
| `categoryColors` | ❌ | 对应分类的标签颜色，不填则自动分配 | `["#16a085"]` |
| `date` | ✅ | 拍摄日期，格式 `YYYY-MM-DD`，用于排序 | `"2026-06-15"` |
| `photographer` | ❌ | 摄影师名字，显示在详情页 meta 区 | `"张三"` |
| `location` | ❌ | 拍摄地点 | `"学校礼堂前"` |
| `intro` | ✅ | 一句话简介，显示在卡片底部 | `"2026届毕业生大合影"` |
| `cards` | ✅ | 照片数组，每项对应一张照片 | 见下方 |
| `content` | ❌ | 详情页额外介绍文字，支持 HTML | `"<h2>毕业快乐</h2>"` |

### `cards[]` 子字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | ✅ | 单张照片标题 |
| `intro` | ❌ | 单张照片说明文字 |
| `image` | ✅ | 照片文件名（相对于当前文件夹） |
| `date` | ❌ | 单张照片日期，不填则继承顶层 `date` |

## 五、编辑现有图集

1. 找到 `data/<图集文件夹>/<图集名>.json`
2. 修改 JSON 内容（增删 `cards`、改文字等）
3. 如果添加了新照片文件，确保 `image` 字段指向正确文件名
4. 提交更改

---

## 六、删除图集

1. 删除 `data/` 下对应的整个文件夹
2. 打开 `data/folders.json`，从数组中移除该文件夹名
3. 提交更改

---

## 七、注意事项（重要）

| 事项 | 说明 |
|------|------|
| ⚠️ JSON 必须合法 | 逗号不能多也不能少，引号必须是双引号。推荐用 VS Code 编辑，自带 JSON 校验 |
| ⚠️ 文件名必须匹配 | JSON 文件名必须与文件夹名**完全一致**，否则 `fetch()` 会 404 |
| ⚠️ 图片路径 | `cards[].image` 只写文件名，系统自动拼接为 `data/<文件夹>/<文件名>` |
| ⚠️ 图片缺失 | 图片加载失败时会显示"暂无图片"占位图，不影响页面运行 |
| ✅ 图片压缩 | 建议上传前压缩图片，避免仓库体积过大 |
| ✅ 同步 folders.json | 每次增删图集后，**务必**同步更新 `folders.json` |

## 八、本地预览方法

由于项目使用 `fetch()` 加载本地 JSON，直接双击 HTML 文件会因浏览器安全限制（CORS）无法加载数据。需要启动本地服务器：

VS Code 插件

安装 `Live Server` 插件 → 右键 HTML 文件 → `Open with Live Server`

## 九、Git 协作流程

1. 从最新 `main` 分支拉取代码
2. 创建自己的分支：`git switch -c feature/add-<图集名>`
3. 按上述步骤添加 / 修改图集
4. 提交并推送：
   ```bash
   git add .
   git commit -m "feat: 添加毕业季合影图集"
   git push -u origin feature/add-毕业季合影
   ```
5. 在 GitHub 上发起 Pull Request，等待 Review 后合并

### 提交信息规范

| 类型 | 说明 | 示例 |
|------|------|------|
| `feat` | 新增图集 | `feat: 添加毕业季合影图集` |
| `update` | 更新已有图集 | `update: 补充运动会图集照片` |
| `fix` | 修复数据问题 | `fix: 修正文件夹名大小写` |
| `docs` | 仅文档变更 | `docs: 更新协作指南` |

如有疑问，请在仓库提 Issue 或联系项目维护者。
